# Syste

Software su misura, assistenza IT e servizi tecnici specialistici. Lavoriamo dal 2001 a Levate (BG).

**Fatti concreti, non promesse.**

## Cosa facciamo

- **Sviluppo**: software su misura per i processi aziendali, dal gestionale interno all'app per chi lavora in trasferta.
- **Hardware**: fornitura e configurazione.
- **Networking**: progettazione e gestione dell'infrastruttura di rete.
- **Servizi tecnici**: stampa 3D e prototipazione, batimetria, fotogrammetria aerea, ispezioni industriali con drone.
